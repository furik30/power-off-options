# Power Off Options (Переработанная версия)

[English](README.md) | [Оригинальный репозиторий](https://github.com/axelitama/power-off-options)

Это полностью переработанный форк расширения **Power Off Options** для GNOME Shell.

Цель этого проекта — модернизация кодовой базы, унификация работы с системными и пользовательскими кнопками, а также полноценная **поддержка Wayland** (включая выключение экрана).

## 🚀 Ключевые особенности (Цели v2.0)

### 1. Единый интерфейс Drag-and-Drop

В отличие от оригинала, где системные и кастомные кнопки настраивались отдельно, этот форк считает **все кнопки равными**.

- **Полная сортировка:** Вы можете перетаскивать (Drag-and-Drop) _любую_ кнопку (Гибернация, Перезагрузка, Свои скрипты) на любую позицию в меню.
- **Удобное управление:** Включайте и отключайте любые кнопки из единого списка.
- **GTK4 Интерфейс:** Современное и чистое окно настроек.

### 2. Нативная поддержка Wayland

Оригинальное расширение использовало команду `xset` для выключения монитора, что не работает в современных сессиях Wayland (Fedora, Ubuntu и др.).

- **Прямая интеграция с Mutter:** Мы используем внутренний API GNOME (`global.backend.get_monitor_manager()`) для мгновенного и надежного отключения экрана в Wayland без внешних костылей.

### 3. Надежная архитектура

- **Единый источник правды:** Вся конфигурация хранится в единой JSON-структуре, что исключает конфликты настроек и баги сортировки.
- **Чистый код:** Расширение переписано с нуля в соответствии с современными стандартами GJS (GNOME JavaScript).

## 🛠 Доступные опции

- **Выключить экран** — Мгновенно гасит монитор (поддержка Wayland и X11).
- **Гибридный сон** — Сон в RAM + копия на Диск (защита от потери питания).
- **Сон, затем Гибернация** — Сначала сон, через время — гибернация.
- **Гибернация** — Сохранение сессии на диск (требуется настройка системы).
- **Мягкая перезагрузка** — Перезапуск только графической оболочки (быстрее полного ребута).
- **Перезагрузка в UEFI/BIOS** — Перезагрузка прямо в настройки BIOS.
- **Пользовательские команды** — Добавление любых своих скриптов или команд.

## 🔧 Установка

### Из исходного кода

1. Клонируйте репозиторий:
    ```
    git clone -b develop https://github.com/furik30/power-off-options.git
    ```
2. Установите через Makefile:
    ```
    make install
    ```
3. Выйдите из системы и зайдите снова (Logout/Login).
4. Включите расширение через приложение **Дополнения** (Extensions).

## ⚙️ Настройка

Откройте настройки расширения:

```
gnome-extensions prefs power-off-options@axelitama.github.io
```

Или нажмите кнопку **"Настроить это меню"** прямо внутри меню выключения.
